ENGINEERING CASE STUDY

so_long

C · MiniLibX · Pixel Buffers · 2D Graphics

Project Background

so_long is a 42 Bangkok tile-based game developed in C with MiniLibX. Beyond making playable levels, I explored how individual pixels and sprite layers are composed into a complete 2D scene.

Technical Implementation

  • Pixel-level rendering: Reading colors from image buffers and writing them to a canvas using pixel offsets, line lengths, and bits-per-pixel information.
  • Layer composition: Rendering grass and floor tiles first, then walls, collectibles, exits, the player, and enemies in order.
  • Transparency: Skipping transparent sprite pixels so foreground objects blend correctly with previously drawn layers.
  • Map validation: Using flood-fill traversal to verify that collectibles and the exit are reachable.
  • Game systems: Managing player movement, enemy behavior, collisions, collectibles, restart, and completion.
  • Animation and portability: Advancing animation frames and handling graphics-library dependencies across Linux and macOS.

Engineering Challenges

The rendering order, transparency handling, moving enemies, underlying tile state, and animation timing must remain consistent. Porting across environments also required careful graphics configuration and cleanup.

What I Learned

I gained practical experience with pixel memory, scene composition, event-driven game logic, graph traversal, resource management, and compatibility between environments.

The playable website demo is a JavaScript browser adaptation using original artwork; the source project is written in C.
