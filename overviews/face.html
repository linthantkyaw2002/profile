ENGINEERING CASE STUDY

Face Attendance

Python · OpenCV · MTCNN · FaceNet · KNN

Project Background

Face Attendance is a Stamford International University project for recognizing registered individuals and recording attendance through a desktop application. I focused on building a consistent recognition pipeline and managing the application environment before prioritizing visual polish.

Technical Implementation

  • Data collection: Capturing facial samples at multiple angles for more representative training data.
  • Preprocessing: Detecting, aligning, and preparing face regions with computer vision tools.
  • Feature extraction: Converting facial images to numerical FaceNet embeddings.
  • Classification: Using K-Nearest Neighbors to compare embeddings and predict registered identities.
  • Attendance recording: Associating recognized identities with recorded attendance entries.
  • Application integration: Working with Python dependencies, camera access, native libraries, and macOS application packaging.

Engineering Challenges

The recognition pipeline depends on lighting, face angles, data consistency, and preprocessing choices. Packaging for Apple Silicon also required resolving Python environment differences, native dependencies, application-bundle settings, and camera permissions.

What I Learned

Reliable applications require more than correct model code. I learned to consider dataset quality, classification evaluation, dependency versions, permissions, and runtime compatibility alongside usability.

The browser demonstration tracks detected faces only. Unlike the original application, it does not perform identity recognition.
