03 / ON MY WORKBENCH

From repetitive commands to reusable workflows.

An independent developer tool inspired by a problem I encountered while building Minishell.

CURRENTLY BUILDING · FLOW CLI

Save the steps. Reuse the workflow.

Flow began with a simple frustration: repeatedly running the same commands after changes to Minishell. I started building a tool to capture working command sequences, save them as named workflows, and replay them without retyping each step.

Today, Flow records and manages command sequences for Bash and Zsh on macOS and Linux.

Where I Want to Take It

My long-term goal is a platform where developers can create and share trusted workflows for project setup, testing, builds, and development environments.

What I’m Exploring Next

  • Sharing and importing workflow templates
  • Prerequisite checks and execution order
  • Portability across environments
  • Workflow previews and safer execution
  • Testing, documentation, and reliability
